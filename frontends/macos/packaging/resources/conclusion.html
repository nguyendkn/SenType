SenType đã được cài đặt / SenType is installed

Đăng xuất rồi đăng nhập lại, sau đó: System Settings → Keyboard → Input Sources → Edit → + → Vietnamese → SenType.

Log out and back in, then add SenType under System Settings → Keyboard → Input Sources.

Gỡ cài đặt / Uninstall: sudo ./uninstall.sh (trong file zip / in the release zip).
